## 功能

### 1. 画面弹幕悬停 +1 / 复制

- 鼠标移到视频画面上飘过的弹幕上，**只钉住这一条**，其他弹幕继续飘。
- 弹幕出现淡粉色描边，旁边出现 `+1`、`复制` 小菜单。
- `+1`：把这条画面弹幕的文本发送到聊天框。
- `复制`：复制这条画面弹幕的文本。
- 鼠标移到菜单上时，被钉住的弹幕保持不动，方便点击。
- 同一条轨道上出现两条相同文本时，也只钉住鼠标命中的那一条。

![](C:\Users\Administrator\AppData\Roaming\marktext\images\35fa40204d2789951f39afbb1aefad41bf03a726.png)

实现方式：在 `document-start` 劫持抖音播放器的 worker Blob，注入 `OffscreenCanvasRenderingContext2D` 补丁，通过 `BroadcastChannel` 把画面弹幕文本、坐标、字体回传主线程，再发送 `pin` 命令把选中的那一条画在固定坐标。

### 2. 屏蔽礼物 / 进场消息

开启后：

- 隐藏左下角/画面上的礼物飘屏提示（如图 1 这类“某某 送为你闪耀 ×1”）。
- 隐藏右侧公屏里的送礼消息，例如“某某：送出了 粉丝团灯牌 ×1”“某某：送出了 为你闪耀 ×1”。
- 隐藏进场、关注、分享、底部“来了/为主播点赞了”等非弹幕提示。
- 只保留普通聊天弹幕。

实现方式：

- 对左下礼物飘屏使用 `GiftTrayPlugin` / `GiftTray` 等组件 class 做 CSS 隐藏。
- 对右侧聊天列表按“送出了”“粉丝团灯牌”“加入了直播间”“来了”等文本和结构做动态过滤。
- 每 650ms 轻量扫描一次，兼容虚拟列表复用节点。

### 3. 自动最高画质

- 进入直播间后自动选择当前可用的最高档位。
- 优先级：`原画 > 蓝光 > 超清 > 高清 > 标清 > 流畅`。
- 会跳过带“登录即享”的锁定档位。
- 用户手动改画质后，本房间不再自动抢回。

### 4. 精简界面

- 隐藏底部礼物栏 `#BottomLayout`，让视频区域向下铺满。
- 播放器控制条保留，右侧聊天区不受影响。

### 5. 设置面板

视频左下角半透明小齿轮，点击打开。

| 设置项                 | 说明                                 |
| ---------------------- | ------------------------------------ |
| 启用 DouyinEx          | 总开关                               |
| 画面弹幕悬停 +1 / 复制 | 视频画面上飘过的弹幕                 |
| 屏蔽礼物 / 进场消息    | 画面礼物飘屏 + 右侧公屏送礼/进场提示 |
| 自动最高画质           | 进房自动切最高可用档                 |
| 精简界面（隐藏礼物栏） | 隐藏底部礼物栏，扩大视频区域         |

设置即时生效并保存在本机。

> 右侧公屏弹幕的 +1 / 复制功能已移除，现在只保留画面飘屏弹幕的 +1 / 复制。

## 安装 / 更新

1. 打开 Tampermonkey 管理面板。
2. 如果已经安装旧版，打开 DouyinEx 编辑，`Ctrl + A` 全选并删除旧内容。
3. 粘贴 `DouyinEx.user.js` 的**全部内容**，包括文件头的 `@grant unsafeWindow`。
4. `Ctrl + S` 保存，刷新直播间。

## 使用

### 画面弹幕 +1 / 复制

1. 确认直播画面上有飘过的弹幕。
2. 鼠标移到其中一条上。
3. 该条弹幕停住，旁边出现 `+1`、`复制`。
4. 点 `+1` 发送；需要当前已登录抖音。
5. 点 `复制` 复制文本。

### 屏蔽礼物 / 进场消息

默认开启。在设置面板关闭“屏蔽礼物 / 进场消息”即可恢复显示。

如果某项仍未隐藏，可以按下面方式排查并反馈对应元素的 HTML。

## 已知限制

- 画面弹幕的命中依赖抖音当前的 `CanvasDanmakuPlugin` / worker 实现；站点大改后可能需要更新。
- 礼物过滤使用组件 class + 文本特征；如果抖音换用新的礼物组件或改文案，可能需要补选择器。
- 自定义表情弹幕：+1 发送的是 `[表情名]` 文本，不保证渲染成原表情。
- 发送依赖抖音登录态和输入框；未登录、被禁言、发送太频繁时会提示。
- 精简界面隐藏整个 `#BottomLayout`，部分直播间底部的商品/活动栏也会一起隐藏。
- 如果抖音把 `<video>` 元素本身全屏，浏览器会把它放到独立顶层，脚本设置齿轮可能不可见；自动画质和精简样式仍然生效。
- 脚本不会自动循环发送，也不会绕过抖音的发送频率限制。

## 排查

打开直播间，按 `F12`，在 Console 查看是否有 `[DouyinEx]` 日志。

常用检查：

```js
// 脚本是否加载
window.__DouyinEx?.version

// 当前房间
window.__DouyinEx?.getRoomId()

// 画面弹幕通道
window.__DouyinEx?.screen.ch

// 画面弹幕是否启用
window.__DouyinEx?.screen.enabled

// 最近一帧收到的画面弹幕数量
window.__DouyinEx?.screen.items.length

// 手动重新执行一次礼物过滤扫描
window.__DouyinEx?.giftFilter.scan()

// 查找聊天输入框
window.__DouyinEx?.findChatInput()
```

如果画面弹幕没有反应：

- 确认设置面板中“画面弹幕悬停 +1 / 复制”已开启；
- 刷新页面，让脚本在页面加载最开始运行；
- 确认 Tampermonkey 中 `@run-at document-start` 和 `@grant unsafeWindow` 没被修改；
- 如果 `screen.items.length` 一直是 0，可能抖音改动了 worker 创建方式，需要更新补丁。

如果礼物消息仍显示：

- 在输入框执行 `window.__DouyinEx?.giftFilter.scan()` 看看是否立即隐藏；
- 如果仍不隐藏，右键该礼物消息 → 检查，复制所在容器的 `outerHTML` 和 `class`，反馈给脚本维护者补选择器。

如果 `+1` 提示“未登录或未找到聊天输入框”：

- 确认抖音账号已登录；
- 确认右侧聊天区展开、底部输入框可见；
- 刷新页面后再试。

如果 `+1` 提示“发送超时”：

- 可能是发送太频繁、内容含敏感词、或账号被限制；
- 等几秒再试，或手动在输入框发送一次确认输入框本身可用。
